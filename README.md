# Angular Photo Gallery

A small Angular app for browsing and showcasing photos in the browser. To see photos section, click Galeria on the nav bar.

**Live site (GitHub Pages):** https://officialaaronvelez.github.io/angular-photo-gallery/

**Repository:** https://github.com/OfficialAaronVelez/angular-photo-gallery

## Local development

```bash
npm install
npm start
```

Then open http://localhost:4200/

## Build

```bash
npm run build
```
